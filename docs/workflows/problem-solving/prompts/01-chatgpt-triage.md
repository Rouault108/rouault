# Prompt: ChatGPT 初動整理

```text
Rouaultで次の問題が発覚しました。
以下の情報だけを使い、入口判定、重大度、R段階、Aレベル、必要成果物を整理してください。原因はまだ断定しないでください。

情報境界:
- この入力に明示された情報だけを根拠にする
- 未提示の過去会話や記憶を根拠にしない
- 推定は推定として明示し、Evidenceで検証可能にする

入力:
- 症状:
- 再現手順またはコマンド:
- 期待結果:
- 実際の結果:
- 失敗ログ:
- 環境:
- branch / commit:
- local差分:
- CI run / log:
- 共有不可情報:

出力:
1. 問題の仮定義
2. 重大度
3. R段階と理由
4. Aレベルと理由
5. 必要成果物
6. 不足情報
7. 次に行う確認
8. 原因断定を避けるべき点
```
