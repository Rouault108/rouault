# Blockquote

## 概要

本書は、`ui-blockquote` の公開契約、入力契約、状態モデル、意味構造、表示契約、および互換性境界を定義します。

`ui-blockquote` は、本文中の引用領域を表現するコンポーネントとします。引用本文を主情報とし、出典情報は存在する場合に限り補助情報として下位に配置します。出典が存在しない場合は `blockquote` 単体で成立させます。出典が存在する場合は `figure > blockquote + figcaption > cite` の構造で成立させます。

本コンポーネントでは、引用本文と出典情報の階層を DOM 構造として固定します。出典の有無、入力面の優先順位、言語属性、引用元 URL は一貫した契約として処理します。

配色、高コントラスト対応、印刷時の分断抑止は、コンポーネント固有のモード分岐ではなく、トークン契約および環境別媒体契約により成立させます。

## 公開契約

公開入力は `variant`、`source`、`cite`、`quoteLang` とします。本文は default slot から与えます。出典入力は `** と **`** の二系統**を持ちますが、両者を同格には扱いません。

初期規則は次のとおりです。

- `source` はプレーンテキスト出典の簡易入力とします。
- `slot="source"` は可視出典の優先入力とします。
- `quoteLang` を引用本文言語の正規公開 property とします。
- 対応する HTML 属性名は `quote-lang` とします。
- `variant` の正規入力値は `default` と `nested` とします。
- 不正な `variant` は受理し得ますが、採用する描画状態は `default` とします。
- `source` および `cite` は前後空白を除去して評価し、空白のみの値は未指定として扱います。

出典入力については、次を契約とします。

- `source` は **プレーンテキスト専用**とします。trim 後の文字列を `figcaption > cite` のフォールバック本文として用います。
- `slot="source"` は **可視出典の優先経路**とします。リンク、強調、書名、複数要素の組合せを許容します。
- `slot="source"` は、**host 直下に置かれた要素**を入力面とします。
- `slot="source"` が割り当てられていても、その要素の `textContent.trim()` が空である場合は、出典入力として扱いません。
- `slot="source"` は、**文字情報を含む可視出典**を前提とします。アイコンのみ、画像のみ、装飾のみの内容は有効入力として扱いません。
- `source` と `slot="source"` が同時に存在する場合、**表示内容は **``** を優先**します。`source` はその場合でもフォールバック本文としてのみ残します。

| 名前        | 種別                 | 必須   | 内容           | 契約                                                                                                                         |
| ----------- | -------------------- | ------ | -------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `variant`   | property / attribute | いいえ | 表示バリアント | `default` / `nested` を正規値として扱うものとします。不正値は受理し得ますが、採用する描画状態は `default` とするものとします |
| `source`    | property / attribute | いいえ | 出典テキスト   | trim 後に空文字列なら未指定として扱うものとします。プレーンテキスト経路とします                                              |
| `cite`      | property / attribute | いいえ | 引用元 URL     | trim 後に空文字列なら `blockquote[cite]` を出力しないものとします                                                            |
| `quoteLang` | property / attribute | いいえ | 引用文の言語   | 正規公開 property とし、対応 HTML 属性名は `quote-lang` とするものとします                                                   |

| 名前            | 種別       | 位置づけ | 内容                                                            |
| --------------- | ---------- | -------- | --------------------------------------------------------------- |
| default slot    | slot       | 正規入力 | 引用本文を与える経路とします                                    |
| `slot="source"` | named slot | 優先入力 | host 直下に置かれた、文字情報を含む可視出典を与える経路とします |

本コンポーネントの責務範囲には、引用本文の表示、出典有無に応じた DOM 構造の切替、`source` と `slot="source"` の優先順位解決、`cite` 属性の伝播、`lang` 属性の決定、バリアントごとの余白差分、および必要な媒体別スタイルの提供を含めます。

出典テキストの自動生成、`cite` の可視リンク化、引用マーカー文字の付与、脚注番号管理、埋め込みカード化、構造化された出典専用 API、独自イベント公開は責務に含めません。

## Property / Attribute 反映契約

公開 property と対応 attribute の意味は一致させます。property 経由の設定と attribute 経由の設定で、意味論上の差分は持ち込みません。

反映規則の基準は次のとおりです。

- `quoteLang` を正規 state とします。
- `quote-lang` は `quoteLang` に対応する HTML 属性名とします。
- `source`、`cite`、`variant` は property / attribute の両経路を許容します。
- いずれの経路でも、評価規則は同一とします。

空値の扱いは次のように固定します。

- `null`、`undefined`、空文字列、および空白のみの文字列は、文字列入力としては未指定相当とします。
- attribute 削除は未指定状態への遷移として扱います。
- property による再設定と attribute の追加・削除は、最終的に同一の内部評価結果へ収束させます。

`lang` 決定規則は次のとおりです。

- `quoteLang` / `quote-lang` が有効な場合は、その値を `blockquote[lang]` に採用します。
- `quoteLang` / `quote-lang` が未指定で、host `lang` が有効な場合は、その値をフォールバックとして採用します。
- `quoteLang` / `quote-lang` と host `lang` の双方が無効である場合、`blockquote[lang]` は出力しません。

| 項目                                          | 反映契約                                                          |
| --------------------------------------------- | ----------------------------------------------------------------- |
| `variant` property / attribute                | 正規化後に同一の描画状態へ収束するものとします                    |
| `source` property / attribute                 | trim 後の文字列を同一規則で評価するものとします                   |
| `cite` property / attribute                   | trim 後に非空の場合のみ `blockquote[cite]` に反映するものとします |
| `quoteLang` property / `quote-lang` attribute | 同一入力面として扱うものとします                                  |
| attribute 削除                                | 未指定状態への遷移として扱うものとします                          |
| `null` / `undefined` / `''`                   | 文字列入力としては未指定相当として扱うものとします                |

## 更新契約

更新契約は、**反応入力** と **描画時計算入力** を分けて定義します。反応入力は、変更それ自体が再描画契約に含まれる入力です。描画時計算入力は、再描画時に参照する入力ですが、それ自体の変更のみを独立した更新保証とはしません。

反応入力は次のとおりです。

- `variant`
- `source`
- `cite`
- `quoteLang`

描画時計算入力は次のとおりです。

- `slot="source"`
- host `lang`

更新時の原則は次のとおりです。

- `variant` の変更は、表示密度のみを再評価します。意味構造の差分は導入しません。
- `source` の変更は、出典あり判定およびフォールバック本文を再評価します。
- `cite` の変更は、`blockquote[cite]` の付与または除去として再反映します。
- `quoteLang` の変更は、`blockquote[lang]` の決定結果を再評価します。
- `slot="source"` および host `lang` は、再描画時に参照する入力とします。これらの動的変更それ自体は、独立した更新保証の対象とはしません。
- `slot="source"` の独立更新保証は、将来追加を検討し得る拡張候補とします。ただし、現契約には含めません。

更新後も維持する優先規則は次のとおりです。

- `source` と `slot="source"` の優先順位は不変とします。
- `slot="source"` に有効な割当てが存在する限り、`source` は可視出典には昇格しません。
- host `lang` は、`quoteLang` / `quote-lang` が未指定である場合に限り参照します。

| 入力種別       | 対象            | 更新契約                                                                                                         |
| -------------- | --------------- | ---------------------------------------------------------------------------------------------------------------- |
| 反応入力       | `variant`       | 変更時に再描画し、DOM 意味構造は変更しないものとします                                                           |
| 反応入力       | `source`        | 変更時に出典あり判定とフォールバック本文を再評価するものとします                                                 |
| 反応入力       | `cite`          | 変更時に `blockquote[cite]` を再反映するものとします                                                             |
| 反応入力       | `quoteLang`     | 変更時に `blockquote[lang]` を再評価するものとします                                                             |
| 描画時計算入力 | `slot="source"` | 再描画時に出典あり判定および可視出典内容へ反映するものとします。独立変更のみの即時更新保証は含めないものとします |
| 描画時計算入力 | host `lang`     | 再描画時に `blockquote[lang]` のフォールバック入力として参照するものとします                                     |

## コンテンツ入力契約

入力面は default slot と `slot="source"` に分けます。両者の役割は混同しません。

各入力面の位置づけは次のとおりです。

- default slot は引用本文の入力面とします。
- `slot="source"` は可視出典の入力面とします。
- default slot には、段落、強調、リンク、コード、リスト等の通常の本文要素を許容します。
- `slot="source"` には、プレーンテキスト、書名、著者名、媒体名、リンク、複数要素の組合せを許容します。
- 出典欄は補助情報領域とし、主要本文を再掲する用途には用いません。

入力面に関する制約は次のように固定します。

- default slot は引用本文専用とします。
- `slot="source"` は可視出典専用とします。
- `slot="source"` の有効性は、**host 直下に置かれた要素**の `textContent.trim()` により判定します。
- `slot="source"` は、**文字情報を持つ出典**を前提とします。アイコンのみ、画像のみ、装飾のみの内容は有効入力としません。
- `slot="source"` にインタラクティブ要素を含めることは許容しますが、出典導線の範囲に限るものとします。
- default slot および `slot="source"` において、フォーム送信、状態切替、破壊的操作を主目的とする UI は公開契約の想定外とします。

| 入力面          | 許容                                                                   | 非推奨 / 想定外                                                 |
| --------------- | ---------------------------------------------------------------------- | --------------------------------------------------------------- |
| default slot    | 段落、強調、リンク、コード、リスト                                     | 見出し、フォーム部品、操作 UI                                   |
| `slot="source"` | 文字情報を含むプレーンテキスト、書名、著者名、媒体名、リンク、複数要素 | 本文の再掲、長文説明、アイコンのみ、画像のみ、装飾のみ、操作 UI |

## 状態モデル

状態は、出典の有無、出典入力の優先順位、言語指定、および表示密度により決定します。

最小状態は、default slot に引用本文のみが与えられた状態とします。この状態では、`blockquote.quote` のみを生成し、`figure`、`figcaption.source`、`cite` 要素は生成しません。

出典状態は、次のいずれかを満たした場合に成立します。

1. `source.trim().length > 0`
2. `slot="source"` を持つ **host 直下要素** が存在し、その `textContent.trim().length > 0`

`slot="source"` 要素の存在のみでは出典状態を成立させません。空白のみのスロット内容、または文字情報を持たない内容は、出典あり状態へ遷移させません。

出典状態では、ルート構造を `figure` とし、その子として `blockquote.quote` と `figcaption.source > cite` を描画します。

`source` property と `slot="source"` が同時に存在する場合、状態遷移条件には両方が寄与し得ますが、**可視出典の内容決定は **``** を優先**します。`source`は`<slot name="source">${source}</slot>` のフォールバック本文としてのみ機能します。したがって、`slot="source"` に有効な割当てがある場合、`source` 文字列は表示しません。

`variant` は表示密度にのみ影響させます。`default` は通常引用、`nested` は引用内引用または補助引用を想定した圧縮状態とします。`nested` では `default` より上下余白を小さくし、左罫線色を muted 系へ寄せます。不正な `variant` 値は保持し得ますが、採用する描画状態は `default` とします。

`quoteLang` / `quote-lang` が存在する場合は、その値を `blockquote[lang]` に採用します。明示入力が空で、かつホスト要素に `lang` 属性が存在する場合は、その値を `blockquote[lang]` に継承します。両方が存在しない場合、`lang` 属性は出力しません。

`cite` は trim 後に非空である場合に限り `blockquote[cite]` に反映します。空白のみの `cite` は未指定として扱います。

| 状態             | 条件                                                 | DOM 構造                                  | 備考                                                                         |
| ---------------- | ---------------------------------------------------- | ----------------------------------------- | ---------------------------------------------------------------------------- |
| 最小状態         | `source` 無効 かつ `slot="source"` 無効              | `blockquote`                              | 引用本文のみで成立します                                                     |
| 出典付き状態     | `source` または `slot="source"` が有効               | `figure > blockquote + figcaption > cite` | 出典を補助情報として下位表示します                                           |
| スロット優先状態 | `source` 有効 かつ `slot="source"` 有効              | 上記 DOM を維持                           | 可視出典は `slot="source"` を優先し、`source` はフォールバック本文に退きます |
| 入れ子状態       | `variant="nested"`                                   | 上記 DOM を維持                           | 余白と左罫線トーンのみを変更します                                           |
| 言語明示状態     | `quoteLang` / `quote-lang` または host `lang` が有効 | `blockquote[lang]`                        | 明示入力を優先し、未指定時のみ host `lang` を参照します                      |
| 引用元明示状態   | `cite` が有効                                        | `blockquote[cite]`                        | 空白値は無効です                                                             |

## DOM / Accessibility

出典なしの正規構造は `<blockquote>` とします。出典ありの正規構造は `<figure>` をルートとし、引用本文を `<blockquote>`、出典を `<figcaption><cite>` で表現します。

```text
[出典なし]
<blockquote class="quote">
  <slot></slot>
</blockquote>

[出典あり]
<figure>
  <blockquote class="quote">
    <slot></slot>
  </blockquote>
  <figcaption class="source">
    <cite>
      <slot name="source">...</slot>
    </cite>
  </figcaption>
</figure>
```

`source` は独立要素として別描画しません。`slot name="source"` のフォールバック本文として埋め込みます。したがって、DOM 契約上、出典表示の実体は常に `figcaption.source > cite > slot[name="source"]` に集約します。

`blockquote.quote` は非インタラクティブ要素とします。`tabindex` および `role` は付与しません。キーボードフォーカス対象は、引用本文そのものではなく、スロット内部に利用者が配置した本来的なインタラクティブ要素に限ります。

`cite` 属性は URL の機械可読な保持に用います。これ自体を可視リンクへ変換しません。可視の出典導線が必要な場合は、`slot="source"` 内にリンク要素を明示的に与える必要があります。

`lang` は引用本文の読上げ文脈を補正するため、`blockquote` 自体へ付与します。`quoteLang` / `quote-lang` を明示入力とし、未指定時のみ host `lang` をフォールバックとして参照します。

本コンポーネントでは、引用を視覚装飾ではなく意味要素として実装します。出典入力を `source` と `slot="source"` に分ける場合でも、意味構造は常に `figure > blockquote + figcaption > cite` に固定します。疑似要素のみに依存した見た目構造は採用しません。

## Accessibility 検証項目

Accessibility に関する契約は、実装意図ではなく検証可能な項目としても維持します。検証時は次の観点を満たす必要があります。

| 検証項目     | 検証内容                                                                                                       |
| ------------ | -------------------------------------------------------------------------------------------------------------- |
| 意味構造     | 出典なしでは `blockquote`、出典ありでは `figure > blockquote + figcaption > cite` を維持すること               |
| フォーカス   | `blockquote.quote` 自体はフォーカス対象にならず、slot 内の本来的なインタラクティブ要素のみが到達可能であること |
| 読み上げ順序 | 引用本文が先、出典情報が後の順で解釈されること                                                                 |
| 言語適用     | `blockquote[lang]` が明示入力優先、host `lang` フォールバックの規則に従って付与または省略されること            |
| 可視出典     | `cite` 属性のみでは可視リンク化されず、可視導線は `slot="source"` 側の明示入力に限られること                   |
| 強制色       | forced-colors 下でも左罫線と本文・出典の区別が失われないこと                                                   |
| 印刷         | 引用本文と出典が分断されず、意味順序が保持されること                                                           |

## Visual Contract

表示契約の基準は次のとおりです。

- 正規の情報順序は、引用本文、出典情報の順とします。
- 左罫線は引用ブロックの構造線として扱い、装飾記号としては扱いません。
- 引用本文は本文色で表示し、出典情報は一段階弱い muted 色、小さい文字サイズ、および中程度ウェイトで表示します。
- `.quote` は縦方向に十分な外側余白を持たせます。
- 左側にのみ内側余白と構造線を持たせ、右側および上下には枠線を持たせません。
- 最初と最後の子要素には余分なマージンを残しません。

これにより、引用領域全体の垂直リズムを安定させます。

`nested` バリアントでは、通常引用より上下余白を短くし、左罫線色を `--border-muted` 系へ切り替えます。これは引用の階層を密度差で表現するための契約とします。タイポグラフィそのものは別系統へ変更しません。

出典行 `.source` は引用本文の直下に短い間隔で配置します。出典ラベルは `cite` 要素で包みますが、視覚上は斜体にしません。引用文そのものと出典表示の視認上の役割を分離するためです。

本コンポーネントは、モード別スタイル分岐ではなく、**セマンティックトークン参照**で成立させます。主な参照トークンは次表のとおりです。

| 用途           | トークン                              |
| -------------- | ------------------------------------- |
| 引用本文色     | `--fg-default`                        |
| 出典文字色     | `--fg-muted`                          |
| 左罫線既定色   | `--border-default`                    |
| 左罫線入れ子色 | `--border-muted`                      |
| 左罫線幅       | `--border-width-thick`                |
| 外側余白       | `--space-6`, `--space-4`, `--space-2` |
| 内側余白       | `--space-4`                           |
| 出典文字サイズ | `--text-xs`                           |
| 出典ウェイト   | `--font-medium`                       |
| 文字間隔       | `--tracking-wide`                     |
| 行高           | `--line-height-normal`                |

## 公開スタイリング契約

本コンポーネントの公開スタイリング面は、セマンティックトークン参照によって成立させます。外部利用者に対して公開する拡張面は、原則としてトークン差し替えに限ります。

公開しない内部面は次のとおりです。

- 内部 class 名
- 内部 DOM の細部
- 内部余白実装
- `::part`
- ホスト要素への class 付与による内部装飾変更

`::part` は現時点では公開しません。局所的な見た目差分について具体的な需要が継続的に確認された場合に限り、最小単位での公開を将来検討し得ます。現契約では、`::part` を前提にしません。

外部から調整可能なものと、公開しないものは次のように区別します。

| 項目                            | 契約                                                 |
| ------------------------------- | ---------------------------------------------------- |
| セマンティックトークン          | 正規のスタイル拡張面とします                         |
| ホスト外側の配置                | レイアウト文脈側で調整可能な外部責務とします         |
| 内部 class 名                   | private 実装とし、依存対象にしないものとします       |
| 内部 DOM 細部                   | private 実装とし、直接上書き前提にしないものとします |
| `::part`                        | 公開しないものとします                               |
| `display` / 内部余白 / 内部罫線 | 外部からの直接上書きを正規拡張面としないものとします |

利用者が見た目を変更する場合は、まずトークン差し替えにより対応します。内部 selector 依存のカスタマイズは互換性対象に含めません。`::part` の追加は、トークン差し替えでは解決できない具体要求が存在する場合に限って検討します。

---

## 環境別の振る舞い

高コントラスト環境では、`forced-colors: active` において左罫線と本文色を維持します。引用本文は `CanvasText` に整合し、出典は `GrayText` に整合します。`forced-color-adjust: auto` を維持し、システム色への適応を阻害しません。

印刷環境では、`blockquote` および `figure` に対して `break-inside: avoid` と `page-break-inside: avoid` を指定し、引用本文と出典が分断されないようにします。また、左罫線色は `#000` に固定し、印刷時の視認性低下を防ぎます。

ダークモード対応はトークン差し替えにより成立させます。`prefers-color-scheme` によるコンポーネント内直接分岐は持ち込みません。

## 関連契約

出典入力は二系統とします。

- 単純な文字列出典を扱う場合は `source` property / attribute を用います。
- リンク、書名の強調、複数要素の組合せ等のリッチな出典表現が必要な場合は `slot="source"` を用います。
- 両者は対等な多重入力とはしません。
- `** は簡易入力、**`** は優先入力**とします。
- `quoteLang` と `quote-lang` は同一入力面とします。
- host `lang` は、明示言語入力が未指定である場合のフォールバック入力とします。

公開契約は次のように固定します。

| 項目                       | 契約                                                                                                                    |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `source`                   | プレーンテキスト出典の簡易経路とします                                                                                  |
| `slot="source"`            | host 直下に置かれた、文字情報を含むリッチテキスト出典の優先経路とします                                                 |
| 出典あり判定               | `source.trim()` が非空、または host 直下 `slot="source"` 要素の `textContent.trim()` が非空である場合に限るものとします |
| 同時指定時                 | 可視出典は `slot="source"` を優先し、`source` はフォールバック本文としてのみ使うものとします                            |
| `cite`                     | 機械可読な引用元 URL を `blockquote[cite]` に保持するものとします                                                       |
| `quoteLang` / `quote-lang` | 同一入力面として `blockquote[lang]` に反映するものとします                                                              |
| host `lang`                | `quoteLang` / `quote-lang` 未指定時のフォールバックとします                                                             |

本コンポーネントでは、可視出典と機械可読な引用元 URL を分離して扱います。平文入力とリッチ入力の双方を受けつつ、表示優先順位と空判定規則を固定します。

## 安定性契約

長期的に互換性を維持する対象は、公開 API と意味構造です。内部実装上の補助構造は、互換性対象に含めません。新機能を追加する場合も、既存の公開 API と意味構造を汚染しないことを優先します。

安定性の対象は次のとおりです。

| 項目                                                 | 安定性契約                         |
| ---------------------------------------------------- | ---------------------------------- |
| 公開 property / attribute 名                         | 安定 API とします                  |
| slot 名                                              | 安定 API とします                  |
| `source` と `slot="source"` の優先順位               | 安定契約とします                   |
| 出典あり判定規則                                     | 安定契約とします                   |
| `quoteLang` / `quote-lang` と host `lang` の境界     | 安定契約とします                   |
| `figure > blockquote + figcaption > cite` の意味構造 | 安定契約とします                   |
| `variant` の意味                                     | 表示密度差分に限る安定契約とします |
| セマンティックトークン参照方針                       | 安定契約とします                   |

互換性対象に含めない事項は次のとおりです。

| 項目                          | 扱い                                                       |
| ----------------------------- | ---------------------------------------------------------- |
| 内部 class 名                 | private 実装とします                                       |
| 内部 DOM の補助要素           | private 実装とします                                       |
| 実装上の最適化手法            | private 実装とします                                       |
| 不正 `variant` 入力値そのもの | private 実装上保持し得る入力とし、描画状態と同一視しません |
| Story 名そのもの              | ドキュメント上の参照名であり、公開 API とはしません        |

---

## 拡張方針

新機能の追加は、機能数の増加ではなく、既存契約の純度維持を優先して判断します。追加候補は、意味構造、入力面、公開スタイリング面を不必要に肥大化させない場合に限り検討します。

現時点で将来追加を検討する価値がある拡張は次のとおりです。

| 拡張候補                       | 位置づけ     | 契約方針                                                                                       |
| ------------------------------ | ------------ | ---------------------------------------------------------------------------------------------- |
| `slot="source"` の独立更新保証 | 第一候補     | `slotchange` 等により独立変更だけで再評価する拡張は検討し得ますが、現契約には含めません        |
| 最小単位の `::part` 公開       | 条件付き候補 | トークン差し替えでは解決できない具体要求が継続する場合に限り検討し得ます。現契約には含めません |

現時点で公開契約へ追加しない拡張は次のとおりです。

| 拡張候補                                | 判断                                                                                 |
| --------------------------------------- | ------------------------------------------------------------------------------------ |
| `cite` の自動可視リンク化               | 可視出典と機械可読 URL の責務境界を崩すため採用しません                              |
| `default` / `nested` 以外の追加 variant | 表示密度差分という現在の `variant` 契約を肥大化させるため採用しません                |
| 構造化された出典専用 API                | `source` / `slot="source"` / `cite` の責務分離で十分であるため、本体へは採用しません |
| 独自イベント公開                        | 非インタラクティブ要素としての契約を損なうため採用しません                           |

新機能が必要な場合は、まず wrapper / adapter 層で吸収できるかを検討します。本体へ追加するのは、意味構造と公開面の純度を保ったまま表現できる場合に限ります。

## 境界条件

不正な `variant` 値は入力として保持し得ますが、採用する描画状態は `default` とします。入力値を host property / attribute へ書き戻して正規化しません。

空白のみの `source` は未指定として扱います。

`slot="source"` に要素が存在しても、その要素が host 直下に存在しない場合、または `textContent.trim()` が空である場合は、出典あり状態へ移行しません。

文字情報を持たない `slot="source"` は有効入力として扱いません。

`source` が空で、`slot="source"` も無効である場合、`figure` は描画しません。

`source` が有効で `slot="source"` が無効である場合、`source` 文字列を `figcaption > cite` のフォールバック本文として描画します。

`source` と `slot="source"` がともに有効である場合、`slot="source"` の割当て内容を描画し、`source` 文字列は表示しません。

空白のみの `cite` は `blockquote[cite]` に反映しません。

`quoteLang` / `quote-lang` が空で host `lang` も存在しない場合、`blockquote[lang]` は出力しません。

`slot="source"` と host `lang` の動的変更は、それ自体を独立した更新保証とはしません。次回の再描画時に評価します。

## Storybook 契約

各 Story はデモではなく**契約確認点**として扱います。将来変更時には、各 Story が固定する契約を維持します。

現時点で実在する Story に基づき、次を固定します。

| Story                   | 固定する契約                                                                                            |
| ----------------------- | ------------------------------------------------------------------------------------------------------- |
| `Default`               | 出典なし最小構成、非インタラクティブ契約                                                                |
| `VariantStateMatrix`    | `default` / `nested` と出典有無の状態マトリクス                                                         |
| `SourceContract`        | `source` の trim、`slot="source"` の優先、`cite` / `quote-lang` 反映契約                                |
| `FocusContract`         | 引用本体は非フォーカス対象であり、出典リンクのみが到達可能である契約                                    |
| `BoundaryConditions`    | 不正 `variant`、空白 `source`、空白 `slot="source"`、host `lang` フォールバック、空白 `cite` の境界契約 |
| `DarkModeTokenContract` | `prefers-color-scheme` 非依存のトークン参照契約                                                         |
| `ForcedColorsContract`  | forced-colors で左罫線と出典色を維持する契約                                                            |
| `PrintStyleContract`    | 印刷時の分断抑止と左罫線印刷色固定の契約                                                                |

実在しない Story 名は、契約確認点として列挙しません。新たな契約確認点を追加する場合は、対応する Story を追加した上で本章へ反映します。

## 実装上の補記

公開 API を拡張する場合は、まず **出典の有無で DOM の意味がどう変わるか**、次に `** と **`** の優先順位が保たれるか**、次に **明示言語入力と host **``** フォールバックの境界が保たれるか**、次に **既存の非インタラクティブ契約と公開スタイリング契約を汚さないか**、最後に **その変更が実在 Story の契約確認点へどう反映されるか** の順で判断します。

`source` と `slot="source"` を独立表示に分離する変更、`slot="source"` の文字情報要件を緩める変更、`cite` を可視リンクへ自動変換する変更、`variant` に意味論的差分を持たせる変更、描画時計算入力を暗黙に反応入力へ昇格させる変更、非インタラクティブ要素である本体へ独自イベントを持ち込む変更は、現契約と衝突しやすいため、慎重に扱います。

## 現実装で未対応の事項

本章は、現行の `blockquote.ts` および `blockquote.stories.ts` を基準として、**契約上または機能上まだ実装で直接は保証していない事項**を整理するものです。本章に記載する事項は、将来の拡張候補または未実装項目であり、現時点の公開契約には含めません。

### 契約上まだ直接保証していない事項

| 項目                           | 現状   | 備考                                                                                                           |
| ------------------------------ | ------ | -------------------------------------------------------------------------------------------------------------- |
| `slot="source"` の独立更新保証 | 未対応 | 現実装は `slot="source"` を描画時計算入力として参照しますが、slot 内容変更だけで即時再評価する契約は持ちません |
| host `lang` の独立更新保証     | 未対応 | `quoteLang` 未指定時のフォールバック参照は行いますが、host `lang` の変更だけを独立した更新保証とはしません     |
| 更新契約の Storybook 検証      | 未対応 | 実在 Story は初期描画と境界条件の確認が中心であり、動的更新契約専用 Story は現時点で持ちません                 |
| `::part` 公開                  | 未対応 | 現実装は `part` を公開せず、公開スタイリング面はトークン差し替えに限定します                                   |

### 機能として未対応の事項

| 項目                                    | 現状   | 判断                                                                                                        |
| --------------------------------------- | ------ | ----------------------------------------------------------------------------------------------------------- |
| `cite` の自動可視リンク化               | 未対応 | 現実装は `blockquote[cite]` への保持のみを行い、可視リンク化は行いません                                    |
| `default` / `nested` 以外の追加 variant | 未対応 | 現実装の `variant` は 2 値のみを正規値とします                                                              |
| 構造化された出典専用 API                | 未対応 | `source` / `slot="source"` / `cite` の分離で扱い、追加の構造化入力は持ちません                              |
| 独自イベント公開                        | 未対応 | 本体は非インタラクティブ要素として扱い、独自イベントは公開しません                                          |
| `slot="source"` の非文字入力対応        | 未対応 | `textContent.trim()` を判定基準とするため、アイコンのみ・画像のみ・装飾のみの出典は有効入力として扱いません |

### 現時点での扱い

未対応事項のうち、`** の独立更新保証** は将来の第一候補とします。`** の最小公開** は、トークン差し替えでは吸収できない具体要求が継続する場合に限って検討対象とします。

それ以外の未対応事項は、現時点では **非対応のまま維持すること自体を設計判断** とします。特に、`cite` の自動可視リンク化、追加 variant、構造化された出典専用 API、独自イベント公開は、現行の責務分離と意味構造の純度を崩しやすいため、本体契約へは導入しません。
